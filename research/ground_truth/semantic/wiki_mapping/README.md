# Cross-wiki move mapping

Generated by `research/ground_truth/scripts/wiki_mapping_report.py` from the JSON files in this folder. Do not edit by hand.

For every boss in the product, each row lines up a product move with the Fextralife and Fandom entries that describe it, and records how they relate. It measures how much two independent human sources disagree, which is a **lower bound** on the gap between the product's movesets and engine-level ground truth.

**Nothing here is ground truth.** Every row is `unverified`. V4 adds runtime and engine evidence to `engine_evidence`; which semantic moves and mappings become ground truth is decided by the project owner, never by tooling or by Claude.

## Relations

| Relation | Meaning |
|---|---|
| `same` | Both wikis describe the same action with the same boundaries. |
| `partial` | Overlapping, but details differ (hit count, follow-ups, conditions). |
| `split` | Divided differently: one entry on one side covers several on the other. |
| `conflict` | The wikis contradict each other. |
| `unclear` | No confident correspondence. |
| `only_fextralife` | Only Fextralife describes it. |
