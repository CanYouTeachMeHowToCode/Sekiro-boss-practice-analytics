# 天守阁弦一郎 TAE 全集分类(草稿,待你审核)

由 `scripts/ai/classify.py` 生成,数据在 `engine/genichiro_castle_tae_classes.csv`。对应计划第 7 步(V4 M5)。

- c7100(一、二阶段)和 c7110(三阶段)的每个 TAE 编号一行,共 353 行。
- **只有带攻击判定或飞行物的编号才可能伤到玩家。** 这类编号共 124 个,每个要么属于你审核通过的招式目录,要么有 AI 证据说明天守阁不会出。其中分到 unknown 的:0 个。
- 其余编号没有攻击判定和飞行物,按证据分类,并标出置信度:

| 置信度 | 含义 |
|---|---|
| 高 | 你已确认,或 AI 和录像一致 |
| 中 | 两次录像里有稳定的规律(前后接什么) |
| 低 | 只凭编号段,或它借用的动画 |

## 怎么审核

用鼠标审核:在终端运行 `python -I research/ground_truth/scripts/ai/catalog_review.py 8765 classification`,然后在 VS Code 里 Ctrl+Shift+P → Simple Browser: Show,打开 http://127.0.0.1:8765。页面上可以按置信度筛选。

也可以直接改这个文件:把"审核"栏的 ☐ 改成 ✅ 或 ❌,不通过时写理由。

建议重点看置信度为"中""低"的行,可以在 DS Anim Studio 里打开对应编号看一眼。重新生成时你的审核会保留。
