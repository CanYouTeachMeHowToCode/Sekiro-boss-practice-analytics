# 只狼原版 · 战斗记忆 Boss 一览

原版(1.06)里能拿到"战斗记忆"的 Boss 共 **17 个**:14 个主线 Boss,加上 1.05 版加入的 3 个"心中"Boss。每个 Boss 的地图、角色编号(`cNNNN`)、AI 脚本和击败标志都直接从游戏文件读出,证据链见[文末](#数据是怎么来的)。

| 文件 | 内容 |
|---|---|
| [`memory_bosses.csv`](memory_bosses.csv) | 本表的完整数据,由 [`scripts/ai/memory_bosses.py`](../scripts/ai/memory_bosses.py) 从游戏文件生成。每个 Boss 一行,包括实体编号、NPC 参数、血条名字编号、记忆掉落链和击败事件。 |
| [`genichiro.json`](genichiro.json) | 弦一郎在游戏里的全部实例,以及每个实例对应哪场战斗。 |

> 地图下的区域名(平田宅邸、苇名城……)是按 Boss 所在位置推断的,**不是**从文件里读出来的。地图编号本身是读出来的。

## 二、同一个模型,出现在多场战斗里

做招式数据时,**不能只按角色编号统计**:同一个模型在不同战斗里用的 AI 或参数不同,能出的招也不同。弦一郎就是这样。虚线是不掉记忆的战斗。

```mermaid

  c7100 -.-> g0["序章(无记忆)<br/>AI 710000 + 特效 200051"]
  c7110(["c7110<br/>巴流 弦一郎"]) --> g3["天守阁 三阶段<br/>AI 711000"]
```

## 数据是怎么来的

每一步都是读游戏文件,没有按名字猜对应关系。

```mermaid
flowchart TD
  A["① 战斗记忆道具<br/>文本 アイテム名.fmg 中 “战斗记忆·…”<br/>例:5202 战斗记忆·苇名弦一郎"]
  B["② 掉落表 ItemLotParam<br/>记忆所在的掉落行,以及链首<br/>例:2080 → 2081"]
  C["③ 通用事件 common.emevd<br/>事件 300 把链首和“击败标志”绑定<br/>例:标志 9303"]
  D["④ 地图事件 mXX.emevd<br/>设置该标志的事件里,死亡条件判断的实体<br/>例:1110801"]
  E["⑤ 地图 mXX.msb<br/>该实体的实例:模型、AI 参数、NPC 参数<br/>例:c7110_0001 · 71100000"]
  F["⑥ NpcThinkParam<br/>AI 参数 → AI 脚本编号<br/>例:711000"]
  G["血条 2003[11] + 文本 NPC名.fmg<br/>名字;“判断 A、启用 B”的事件给出前一阶段<br/>例:1110800 c7100 → 1110801 c7110"]
  A --> B --> C --> D --> E --> F
  D --> G
  H["“心中”Boss:没有击败标志<br/>由通用事件 296–298 直接发放记忆<br/>Boss 取名字与记忆一致的血条"] -.-> E
```

重新生成:

```text
python -I research/ground_truth/scripts/ai/memory_bosses.py research/ground_truth/characters/memory_bosses.csv
```

游戏目录读自 `research/ground_truth/local.config`,只读不写。
